# Forever Companion v0.8 — Equipment Interface Pass

A static HTML website for GitHub Pages. Upload `index.html` and the complete `assets/` directory together at the repository root.

Updates:
- Actual 16-slot character window arrangement, plus weapon slots
- Curated WoW icon pack images integrated throughout gear and spells
- Original 2004 fan-site artwork in character and dungeon panes
- Interactive equipment inspection and more faithful black/gold window proportions
- Refined leather, stone, parchment and blue-black tooltip treatment

Limitations:
- This is not a literal pixel-perfect copy of the WoW client, and exact item icons are not all mapped yet.
- Equipment slots show recommended targets, not live equipped items.
- Only levels 10–19 have curated target lists; other brackets remain transparently unfilled.
- Checklists use local browser storage, not shared party sync.

Art: user-supplied WoW icon pack and original 2004 fan-site kit. Follow Blizzard fan content usage terms if distributing. Not affiliated with Blizzard.
